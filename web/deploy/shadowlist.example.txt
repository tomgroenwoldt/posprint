# Terms that make a message vanish quietly.
#
# A match is accepted with a normal success response, charged against the
# sender's quota, written to the log, and never printed. Nobody is told. See
# "The quiet filter" in web/README.md.
#
# THIS FILE IS AN EXAMPLE AND THIS REPOSITORY IS PUBLIC. Do not point
# POSPRINTWEB_SHADOWLIST at it. The whole premise of a shadow filter is that
# the sender believes their message printed; a published list tells them
# otherwise and doubles as a checklist of what to avoid. Keep the real one
# outside the repository - /etc/posprintweb-shadowlist.txt, mode 0600 - and
# leave this here only to show the format.
#
# One term per line, case-insensitive. Matched on letters and digits only, so
# spacing, punctuation and accents between them do not help: "s h i p" matches
# "ship". Blank lines and lines starting with # are ignored.
