# Terms that make a message vanish quietly.
#
# A match is accepted with a normal success response, charged against the
# sender's quota, written to the log, and never printed. Nobody is told. See
# "The quiet filter" in web/README.md.
#
# Copy this somewhere real and point POSPRINTWEB_SHADOWLIST at it:
#     cp shadowlist.example.txt /etc/posprintweb-shadowlist.txt
#
# One term per line. Matching is case-insensitive, ignores accents, and is done
# on WORD BOUNDARIES - "ass" will not match "class" or "passport". Terms of
# five characters or more are additionally matched with separators removed, so
# f-u-c-k and f.u.c.k are caught too.
#
# A false positive here is invisible: the sender is told it printed and you get
# a log line nobody reads. So prefer specific terms over broad ones, and check
# the log occasionally to see what it has been catching.
